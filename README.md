# 🌊 Seal World

Projeto desenvolvido como parte dos estudos em **HTML** e **CSS**, com o objetivo de praticar a construção de páginas web responsivas, estilização com CSS externo e organização de conteúdo visual.  
O projeto **Seal World** apresenta uma página temática focada em focas, com layout agradável, imagens, textos e estilos customizados.

## 🚀 Tecnologias Utilizadas

- HTML5  
- CSS3

## 🎯 Objetivos do Projeto

- Aplicar conceitos fundamentais de HTML e CSS  
- Estruturar uma página responsiva com elementos semânticos  
- Estilizar conteúdo com CSS externo  
- Trabalhar com imagens, fontes e cores

## 🧠 Aprendizados

- Uso correto das tags HTML semânticas
- Estruturação de conteúdo em seções (`<header>`, `<main>`, `<section>`, `<footer>`)
- Aplicação de estilos com seletores CSS
- Prática com margin, padding, cores, fontes e imagens
- Responsividade básica com media queries (caso tenha usado)
